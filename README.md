# 3NITY · Encargos

Formulario para que los clientes pidan un encargo de impresión 3D: nombre, WhatsApp, qué quieren, cantidad y colores, tamaño, para cuándo, presupuesto y un link de referencia.

Cada envío llega por correo a **3nityccs@gmail.com** a través de [FormSubmit](https://formsubmit.co) (gratis, sin cuenta). El correo trae un link para escribirle al cliente por WhatsApp con un toque.

- **Publicado en:** https://niconania.github.io/3nity-encargos/ (GitHub Pages, rama `main`).
- **Cambiar el correo:** la constante `DESTINO` en `index.html`. Un correo nuevo tiene que activarse una vez, con el botón que FormSubmit manda la primera vez que llega un envío.
- **El QR:** `qr-encargos.png` y `qr-encargos.svg` apuntan a la dirección publicada.
